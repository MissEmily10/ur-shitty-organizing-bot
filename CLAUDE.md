# Правила для Claude в этом репозитории

- Общение с владелицей на русском.
- Новые идеи и фичи, которые она присылает, **записывать в `ROADMAP.md`, а не реализовывать**, пока она явно не скажет «делаем» или не отменит это правило.
- Бот задеплоен на Render из ветки `main` (автодеплой при пуше), вечерний пуш дёргает cron-job.org по ссылке `/remind/<секрет>`. Не ломать `main`: черновики — в отдельные ветки (`draft/...`).
- Ключи (Telegram, Hugging Face, Notion) хранятся только в переменных окружения Render, никогда не в коде и не в чате.
