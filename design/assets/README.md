# Картинки из Figma

Сюда кладутся экспортированные из Figma картинки. Бот берёт их вместо временных заглушек.

| Файл | Размер | Что это |
| --- | --- | --- |
| `banner_menu.png` | 1280 × 640 | баннер главного меню |
| `banner_razbor.png` | 1280 × 640 | разбор входящих |
| `banner_projects.png` | 1280 × 640 | проекты |
| `banner_ask.png` | 1280 × 640 | спросить ИИ |
| `banner_schedule.png` | 1280 × 640 | расписание |
| `banner_settings.png` | 1280 × 640 | настройки |
| `banner_report.png` | 1280 × 640 | недельный отчёт |
| `banner_checkin.png` | 1280 × 640 | дневной чек-ин |
| `banner_evening.png` | 1280 × 640 | вечерний разбор |

Подпись и кнопки бот ставит под картинкой сам, поэтому текст на баннере — только название раздела (или вообще без текста).
