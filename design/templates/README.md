# Выкройки для дизайна

- `banner_template.png` — выкройка баннера раздела 1280 × 640 px: поля 64 px (синяя рамка — безопасная зона, Telegram может подрезать края превью), слева зона названия, справа — иллюстрация или персонаж стиля. Подпись и кнопки бот ставит под картинкой сам, поэтому текст на баннере необязателен.
- `styles_preview.png` — как сейчас выглядят временные баннеры «Меню» в каждом стиле (обычный, формальный, кавай-тян, коуч, саркастичный друг, дворецкий, пират, Эминемовна, свой персонаж).

- `timetable_template.pdf` / `.png` — выкройка PDF «Моё расписание» (A4 альбомная, 842 × 595 pt): сетка по часам, колонки дней,
  высота карточки — длительность занятия (окна — пустое место, пересекающиеся занятия — рядом), карточки
  уроков (время, кабинет, номер и предмет, преподаватель, «через неделю: …»), занятия вне школы — зелёные. Данные выдуманные.
  Отдельно от календаря основного расписания (`/schedule`). Цвета и шрифт — из `design/tokens.json`.

## Куда класть готовые баннеры

- Общий баннер раздела: `design/assets/banner_<раздел>.png`.
- Баннер под стиль: `design/assets/styles/<стиль>/banner_<раздел>.png`. Стили: `formal`, `kawaii`, `coach`, `sarcastic`, `butler`, `pirate`, `eminemovna`, `custom`.
- Разделы: `menu`, `spheres`, `projects`, `types`, `notes`, `razbor`, `ai`, `ask`, `plan`, `schedule`, `report`, `settings`, `help`, `team`, `checkin`, `evening`.

Порядок: баннер стиля → общий баннер → ИИ-баннер из `/banners` → временная заглушка. Не обязательно рисовать все разделы для каждого стиля — где картинки нет, бот возьмёт общую. Начать удобно с `menu` для каждого стиля.
