# Что проверить: этап 3, командный режим

Перед проверкой: Render → **Events** → последний деплой **Live**. Для проверки нужен второй аккаунт Telegram (подойдёт друг или второй номер).

Если что-то сломается, бот пришлёт «⚠️ Что-то пошло не так…». Скопируйте текст целиком.

## 1. Приглашение
- [ ] `/start` → в меню есть «👥 Участники» и «🎟 Пригласить».
- [ ] `/invite Аня` (или кнопка «🎟 Пригласить» → написать имя ответом) → пришли код вида `ABCD-2345` и готовое сообщение со ссылкой.
- [ ] В Notion рядом с «Входящими идеями» появилась таблица «Участники бота» со строкой «Аня» и кодом.

## 2. Вход второго человека
- [ ] Со второго аккаунта написать боту что угодно **без кода** → бот просит код. Вам ничего не приходит.
- [ ] Открыть ссылку из приглашения (или прислать код) → «✅ Добро пожаловать» и меню **без** команд владелицы.
- [ ] Вам пришло «🎉 Аня … вошёл(ла) по приглашению».
- [ ] Тот же код второй раз не работает.

## 3. Работа участника
- [ ] Участник присылает заметку → в Notion у неё колонка «Автор» = его имя.
- [ ] У участника в `/razbor` только его заметки, у вас — только ваши.
- [ ] Проекты общие: участник видит ваши проекты и может добавить свой, но не может удалить.
- [ ] Участник пробует `/invite` → ничего не происходит.

## 4. Управление
- [ ] `/members` → видно участника; «🗑 Убрать» → подтверждение → участнику пришло «доступ закрыт», его сообщения снова просят код.
- [ ] `/invite Петя` → `/members` → «❌ Отозвать код» → код больше не работает.

## 5. Вечерний пуш
- [ ] Ссылка из `/remindlink` с `?force=1` → пуш пришёл и вам, и участнику (если у него есть неразобранное).

## Лимиты (по желанию)
У участников по умолчанию 30 заметок и 20 запросов к ИИ в сутки, у вас без ограничений. Поменять: в Render → Environment добавить `MEMBER_DAILY_LIMIT` и `MEMBER_AI_LIMIT`.

## Что прислать мне
По каждому пункту ✅ или ❌, для ❌ — что нажимали и что ответил бот.
